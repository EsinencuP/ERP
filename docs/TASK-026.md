# TASK-026 — Performance + Polish

Выполнено 20.10.2026. Эта задача не закрывает TASK-027—030 или CHECKPOINT-05.

## Изменения

- Все 31 UI-страницы имеют соседний `loading.tsx`. Общие table/detail/dashboard/form/board skeletons переиспользуются через re-export; существующие специальные skeletons сохранены. Корневая граница загрузки охватывает также ожидание dashboard layout. Next.js создаёт Suspense автоматически по файловому соглашению.
- `error.tsx` есть в корне и группах `(auth)`/`(dashboard)`. Общая граница показывает понятное сообщение, непрозрачный digest, повторную загрузку и переход к обзору. Ошибки Result продолжают отображаться через ErrorPanel; отказ PostgreSQL не превращается в пустые данные или demo.
- EmptyState получил общую иллюстрацию на CSS tokens и необязательное действие. В списках CRM, Finance, Inventory, HR и Projects доступны соответствующие кнопки создания с учётом роли и состояния страницы.
- Подключена настоящая cmdk-палитра через существующие Command primitives. Отдельный chunk загружается при первом открытии. Поиск охватывает страницы, разрешённые действия и прежний реестр документов; одновременно монтируется не более восьми найденных документов. Поиск по всем нормализованным сущностям не заявляется.
- Cmd/Ctrl+N использует существующие формы контакта, сделки, счёта, платежа, расхода, товара, склада, сотрудника, отпуска, задачи, проекта и приглашения. В карточке активного товара открывается StockMovement. На вложенных обзорных страницах выполняется основной сценарий создания модуля; там, где его нет, открывается палитра.
- Общий provider хранит актуальный callback/доступность формы. Навигационный `create=1` потребляется однократно, удаляется только этот параметр; остальные параметры и hash сохраняются. Ввод, IME/repeat, открытые формы и занятые операции не открывают вторую форму.
- Существующий Sidebar Sheet используется строго при ширине <768 px. Палитра закрывает мобильную навигацию перед открытием; Radix обрабатывает Esc/focus trap. Команда выполняется после закрытия палитры, чтобы фокус корректно перешёл в новую форму.
- Entrance эффекты общих Dialog/ConfirmDialog дополнены opacity-анимацией без нарушения позиционирования. Route/template, panel, table, button и остальные shared primitives сохраняют свои эффекты; глобальный reduced-motion ограничивает и entrance, и skeleton animations.
- Новые сообщения переведены на EN/RU. EUR, настройки компании и серверная RBAC не изменены.

## Проверки

`npm run build`, `npx tsc --noEmit`, `git diff --check`: PASS. Нет `: any`, `console.log` и hex-цветов в компонентах. Все 1934 пары каталогов совпадают по ключам и placeholders; отсутствующих статических t-ключей и кириллицы в английских значениях нет. Новые тестовые файлы не создавались, проверки выполнены временными browser/Node сценариями.

Локальная production-сборка Next.js 15.5.28 работала с настоящей PostgreSQL 17.10, без demo fallback. Использован отдельный временный workspace с ADMIN/READONLY.

| Сценарий | Результат |
| --- | --- |
| Cmd/Ctrl+N в основных рабочих списках, включая CRM | Одна правильная форма; Esc закрывает её |
| Палитра → New invoice; Finance dashboard → Cmd/Ctrl+N | Открывается форма счёта, intent удаляется |
| Ввод в поиске и Ctrl+N; форма товара и Ctrl+K | Вторая форма/палитра не открывается |
| `inventory?q=bolt&create=1#items` | После открытия остаётся `inventory?q=bolt#items` |
| Meta+N и Meta+K | Формы и палитра открываются |
| Пустая выдача; повторное открытие палитры | Понятный empty state, запрос при открытии очищается |
| 12 документов реестра | В выдаче максимум 8; точный поиск 12-го находит его и открывает `/finance/documents?q=...` |
| Создание товара через клавишу и сохранение | В PostgreSQL одна Product, один audit; EUR 12.50 = 1250 евроцентов |
| Cmd/Ctrl+N в карточке товара | Открывается Record stock movement |
| READONLY, в том числе `?create=1` | Создание не открывается, в палитре нет create/admin команд |
| 375 px, переход Sidebar → palette | Одна модальная поверхность, горизонтального переполнения нет |
| 767 / 768 px | Sheet / desktop Sidebar соответственно |
| Esc из Sidebar/палитры | Фокус возвращается на соответствующую кнопку |
| RU, dark, reduced motion | Локализованные команды, обе темы; длительность анимации при reduce — 0.01 ms |
| Искусственное отклонение RSC-модуля в browser interception | Граница показывает TASK026_SMOKE без текста исключения; Try again восстанавливает страницу |
| Финальный обычный browser smoke | Неожиданных pageerror нет |

Инъекция ошибки существовала только в перехваченном браузерном ответе, исходники и данные приложения для неё не менялись. Временный workspace, пользователи, 12 документов и товар удалены. Исходные 6 invoices и 118 conversion audits сохранены. Запущенные для проверки Next.js/PostgreSQL остановлены. Внешнее развёртывание не проверялось.
