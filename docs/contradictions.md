# Журнал противоречий

На текущем этапе противоречий между законами мастер-плана не обнаружено.

`Result` применяется к бизнес-операциям и операциям с данными; React-компоненты возвращают JSX, а HTTP routes сериализуют Result. Значения палитры централизованно объявлены в CSS variables. Тестовые файлы вне CHECKPOINT не создаются.

При появлении конфликта зафиксировать дату, задачу, конфликтующие требования и варианты решения. Зависимую реализацию остановить до разрешения.
