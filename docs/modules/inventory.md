# Склад

Ниже описан действующий каталог Document-слоя. TASK-002 добавляет нормализованные Product/Warehouse/StockItem/StockMovement; их связи и ограничения описаны в [database.md](database.md). Перевод UI и транзакционные сервисы движений — отдельный этап.

DocType `Product`: `title` — наименование, `subtitle` — артикул, `amount` — цена единицы в копейках, `quantity` — целый неотрицательный остаток, `notes` — описание/место хранения.

Сервис автоматически выводит статус из остатка: 0 — Нет в наличии, 1–3 — Мало на складе, 4+ — В наличии. Порог пока общий и фиксированный как бизнес-правило, не цветовой токен. Стоимость запасов — сумма `amount × quantity`.

Actions: `getProducts`, `createProduct`, `updateProduct`, `deleteProduct`. Контроль версий предотвращает потерю параллельных изменений. Это каталог с прямым редактированием остатка; партии, склады, приходы/расходы, резервы и уникальные SKU потребуют отдельных моделей и транзакций.
