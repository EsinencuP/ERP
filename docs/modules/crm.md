# CRM

Этот документ описывает текущий интерфейс и его переходный Document-слой. Нормализованные Prisma Contact/Deal/Activity и их связи добавлены TASK-002 и описаны в [database.md](database.md); перевод UI на них выполняется отдельно.

DocType `Deal`: `title` — название сделки, `subtitle` — компания/контакт, `email`, `amount` — бюджет в копейках, `date` — план закрытия, `notes`.

Статусы: Новая → Переговоры → Предложение → Выиграна / Проиграна. Таблица и kanban используют одну модель. Перемещение проверяет версию, workspace и права, создаёт audit event. Выигрыш сделки не создаёт счёт автоматически: это отдельная будущая workflow-операция.

Публичные Server Actions: `getDeals`, `createDeal`, `updateDeal`, `deleteDeal`. Поля проверяются `schema.ts`; UI задаётся `config.ts` и `components/crm-workspace.tsx`. Дедлайны и суммы не являются прогнозом выручки. Контакты пока хранятся полями сделки, отдельная адресная книга запланирована.
