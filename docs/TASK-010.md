# TASK-010 — CRM Forms

Статус: закрыт 18 октября 2026. Проверки общего CRM — [CHECKPOINT-02.md](CHECKPOINT-02.md).

ContactFormSheet переиспользуется для создания и редактирования из таблицы контактов и редактирования из detail. Поля: имя, компания, email, телефон, адрес, этап и комментарий. Старый ContactEditDialog удалён. Данные проходят прежние createContact/updateContact, tenant/RBAC, version и audit; новой миграции или зависимостей нет.

Sheet использует shared primitive с modal=false: overlay отсутствует, фон доступен для pointer/focus, body scroll не блокируется. Внешний поиск/сортировка не закрывают форму и сохраняют draft. Snapshot id/version фиксируется при открытии. Параллельная bulk-мутация и открытие второй формы недоступны; чтение таблицы остаётся доступным.

RHF + zodResolver используют contactFormSchema из общей contactSchema. mode и reValidateMode — onBlur: inline ошибки имени/email появляются до submit. Полная проверка перед записью также выполняется. Cmd/Ctrl+Enter внутри формы сохраняет, Escape/Отмена/X закрывают. При выполнении запроса закрытие и повторная отправка заблокированы. Пустые необязательные поля нормализуются сервером, email приводится к lower case.

Sonner toast.success сообщает о подтверждённом commit; toast.error — о невалидной отправке, Result error или неизвестном сетевом результате. Ошибки при blur показаны только рядом с полями. После CONFLICT/network uncertainty draft сохранён, повторная запись блокируется; есть «Закрыть и обновить». Автоматического повтора create нет. Подтверждённая запись не объявляется неуспешной из-за дальнейшего чтения.

Фокус при открытии — имя. При закрытии из таблицы актуальная кнопка находится по стабильному DOM id, поскольку TanStack может пересоздать узел; если строка уже исчезла, используется поиск. Detail возвращает фокус на кнопку редактирования. Desktop — правая панель до 512 px, mobile — полная ширина с отдельной прокруткой полей и фиксированным footer. Обычные modal Sheet/sidebar сохраняют прежний режим; общий primitive получил необязательный closeDisabled.

Проверены создание/редактирование, оба shortcut сохранения, Escape с отменой draft, inline blur и оба toast, незаблокированный поиск с сохранением draft, конфликт при изменении stage за открытой формой, readonly/agent и сетевой abort. Финальные build/typecheck и проверки CHECKPOINT-02 приведены в отдельном отчёте.

Scope: только нормализованные Contact forms. Activity Composer и прежние Document-формы других модулей не заменялись. В explicit demo нормализованные контакты требуют подключения workspace; создание недоступно. Автосохранения и миграции Document-данных нет.
